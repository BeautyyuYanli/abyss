---
name: proposal-apply-simplifications
description: Apply requested revisions and relevant complexity-review findings to the proposal while preserving the user's requirements.
---

Read the proposal at the location described in the incoming handoff and evaluate its complexity review. For requested revisions, apply the pending user-requested edits to that proposal in place. Apply relevant simplifications that preserve the user's requirements, including the requested edits. A review with no useful simplifications still requires applying the requested edits; leave the proposal unchanged only when neither is needed.

Resolve uncertainties affecting the proposed changes with the user before applying them.

Return a natural-language handoff stating the task, final proposal location, required delivery scope, affected sections, and what changed and why. For requested modifications, cover both the requested edits and accepted simplifications.
