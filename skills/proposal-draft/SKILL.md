Create the initial proposal draft at `.context/proposals/YYMMDD-<slug>.md`, creating the directory if needed. Use the supplied task text or, when no task is specified, the recent conversation.

Discuss uncertain proposal decisions with the user before completing the draft.

Return a natural-language handoff stating the task, draft location, and that this is an initial proposal requiring delivery of the full final text. Carry the necessary task context forward in the text.
