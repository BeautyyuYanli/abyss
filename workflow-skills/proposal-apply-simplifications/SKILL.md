---

Read the proposal at the location described in the incoming handoff and evaluate its complexity review. Apply relevant simplifications that preserve the user's requirements; when none are useful, leave the proposal unchanged.

Resolve uncertainties affecting the proposed changes with the user before applying them.

Return `done` with a natural-language handoff stating the task, final proposal location, required delivery scope, affected sections, and what changed and why. For requested modifications, cover both the requested edits and accepted simplifications.
